Instalar

Execute localmente

Você precisa de Node.js 22.22.3+ na série 22.x ou 24.22.2+ na série 24.x e de npm, que vem com o Node.js. Docker Compose é necessário para a integração com simuladores, não para abrir a interface inicial.

Interface de desenvolvimento

git clone https://github.com/bloodf/Open3DFarmManager.git
cd Open3DFarmManager
npm ci --ignore-scripts
npm run dev

Abra http://127.0.0.1:3000. Você verá a interface de desenvolvimento. Esse comando não cria contas, não configura banco de dados e não conecta impressoras. Autenticação e integrações começam desabilitadas e exigem configuração própria.

Hospedagem própria

O guia de hospedagem implanta uma aplicação e o seu banco PostgreSQL dedicado, em uma VM Linux limpa com Docker Engine e o plugin Compose. Resumo das etapas:

  1. Preparar o deploy com a imagem de release e o arquivo .env privado.
  2. Inicializar segredos e o banco de dados, com um dono de migração dedicado.
  3. Configurar o proxy reverso com TLS válido e WebSocket.
  4. Criar o primeiro proprietário com o token de uso único.
  5. Parear um Connector contra um simulador.
  6. Habilitar cada subsistema opcional de forma deliberada.

Leia o guia completo de hospedagem própria (em inglês).

Em desenvolvimento. Mantenha credenciais e configuração privada fora do Git. O projeto não é uma versão pronta para operar uma farm em produção, e a aceitação em hardware permanece aberta.
