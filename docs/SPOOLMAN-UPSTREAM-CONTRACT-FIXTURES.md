# Spoolman upstream contract fixtures

Run `node scripts/test-spoolman-upstream-contract.mjs` with Node 22.22.3 and Docker. The image must be present locally: `ghcr.io/donkie/spoolman@sha256:1ebb4f6a62c2e72a07f18b07ebfdbd96322f5bc2eb72570af3088f68d7c393b1` (v0.27.1, image source revision `ff8efd517b76a4b2783f29c89e9b9fbcd8cd167b`). The runner uses a fresh container with `--network none`, no published ports or mounts, and executes requests on its loopback interface. It removes the container and its anonymous volumes in `finally`. It never connects to a printer or an existing Spoolman service. A forced termination that prevents `finally` may require removing the uniquely named `o3dfm-contract-548-*` container after verifying ownership.

The [JSON corpus](../tests/fixtures/spoolman/upstream-contract/requests.json) records requests derived from the following source and responses captured on 2026-11-21 from that isolated image. Setup POSTs create original synthetic inventory and are not attributed to a client. The runner compares status and complete JSON bodies, replacing only `registered`, `first_used`, and `last_used` timestamps after checking their format. Sequence matters: the usage request changes the synthetic spool before later reads. IDs and numerical values are captured, not estimates. Fixture inputs are examples of client parameters, not recordings of the clients running. No upstream source code is copied into this project; the cited projects retain their own licenses.

The macro-to-Moonraker remote method is not replayed against Spoolman; no macro or printer was executed. The Home Assistant client above is a community integration, not Home Assistant Core. The Moonraker proxy can forward arbitrary requests, and is not itself exercised here. These fixtures cover selected community plugins, not all OctoPrint, OrcaSlicer or Home Assistant integrations. WebSocket events, plugin startup, error handling, authentication, other filters, archive transitions, and multi-client concurrency remain untested. Source inspection and direct Spoolman replay do not establish end-to-end client compatibility.
