# FDM catalog verification

All sources linked below were accessed on 2026-11-22. Scope: the 28 FDM entries in the supplied fleet snapshot (15 Bambu Lab, 8 Creality, 4 Anycubic, 1 Snapmaker). The snapshot's Elegoo entries are all resin, and it has no other FDM brand, so no Elegoo FDM row exists. Dimensions are millimetres (X × Y × Z). Temperatures are maximum nozzle / bed in °C. No printer or LAN device was contacted.

Rules used in this table:

- A value counts as verified only when the linked manufacturer page, spec sheet, manual or official open-source repository states it. Third-party sources appear only as supporting context and are labelled as such.
- `unverified` means the official sources listed were consulted and did not establish the value. The note says what was tried. It does not mean the feature is absent.
- Ethernet is not inferred from Wi-Fi, and a LAN-capable network interface does not by itself prove a usable local protocol.
- Protocol and port values for a brand come from that brand's published documentation or official client code. A family-wide document is applied to a model only when its scope names the model or the model's series. Otherwise the row says so.

## Differences from the prototype

- **Bambu ports.** The prototype's `bambu-mqtt` family names the `device/<serial>/report` topic but no port, FTP channel or camera port. Bambu publishes MQTT 8883, FTP 990 plus a passive range of 50000–50100, video 322/6000 and SSDP 1990/2021 (B1). The prototype also does not model B4: outside Developer Mode, third-party control and print start need authorization or Bambu Connect.
- **Bambu Developer Mode scope.** The fleet's `lan_only_mode` and `developer_mode` fields cover every Bambu model. The wiki's Developer Mode sections do not cover H3C (B3 names "H2 Series"), and H2S cannot use Developer Mode while laser or cutting functions are in use.
- **Bambu "high" confidence.** The prototype rates all 15 Bambu models `high`. The maker's port table is family-wide and does not split the video ports by model. The X1 series also needs a microSD card for LAN printing (B2).
- **Bambu tool counts.** X2D (two nozzles) and H2C (two nozzles, single and dual volumes) are marked unverified in the prototype. Both spec sheets confirm them. H3C's nine tools are confirmed by its spec sheet ("SwapTek 9-Tool Switching").
- **Creality port 9999.** The prototype hard-codes `ws://<ip>:9999` for all eight Creality models. Creality's own client uses 9999 only as the plain-WebSocket path. Its preferred path reads `/info` over HTTPS 443 and uses the `wssPort` that `/info` returns (C1). Camera selection depends on the reported flag (C2). The prototype lacks secure WebSocket transport and both camera paths.
- **Creality Moonraker and Fluidd.** SPARKX i7 (Fluidd, Moonraker, SSH), K2 SE 4C and Creality Hi (root plus Fluidd) expose Klipper web tooling according to Creality. The prototype places them only in `creality-ws`. No official page states a Moonraker port for them.
- **Creality K3 tool count.** The prototype's model profile defaults K3 to one tool. Creality describes four interchangeable nozzles ([K3 FAQ](https://wiki.creality.com/en/k3-flagship-series/k3/faq)). The fleet comment agrees with the maker.
- **Anycubic MQTT.** The prototype's `anycubic-mqtt` family leaves the port open (`mqtts://<ip>:<port>`) at `low` confidence. Anycubic documents LAN Mode for Kobra X, Kobra 4, the Kobra 3 series and the Kobra S1 series, but publishes no protocol or port. Its LAN Mode is documented for Anycubic Slicer Next only and disconnects the cloud. Neither Kobra 3 Max V2 nor Kobra S1 Max is named in the series guides.
- **Snapmaker U1.** The prototype gives the U1 a separate `snapmaker` family with `unknown` confidence. Snapmaker's official repositories ship Klipper, Moonraker (port 7125 in the published config) and Fluidd for the U1, so it fits the Moonraker family. The prototype's four tools match the spec page.
- **Specs the earlier draft lacked.** P1P, P1S, X1E, H2S, Creality Hi and U1 had no build volume or temperatures. All now come from official spec sheets. X1E's nozzle maximum is 320 °C, not the 300 °C of the rest of the X1 line. X2D's bed is 120 °C. H2D Pro's volume and bed temperature remain unverified.
- **Not evidence.** The prototype's simulated payloads (`PrinterScreen.tsx` labels them "illustrative … NOT verified schemas"), the firmware versions in fleet comments and its accessory or slot assumptions are not measurements. This review did not verify individual commands, authentication flows or accessory combinations.
