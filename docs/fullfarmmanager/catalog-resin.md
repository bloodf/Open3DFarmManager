## Differences from the prototype

- The prototype snapshot (`packages/connector/src` and `docs/compatibility`) contains Bambu, Creality, Anycubic/Kobra, and Moonraker families, but no resin printer driver or resin-model compatibility declaration. A resin model in the fleet does not imply support.
- No reviewed official manufacturer source establishes MQTT 8883, FTPS 990, Moonraker 7125, SDCP UDP 3000/WS 3030, or any other public direct printer protocol/port for these resin models. Treating Wi-Fi, Ethernet, a mobile app, or file-transfer support as proof of a local command API is unsupported.
- Formlabs documents a Formlabs Local API for local-network integrations; its developer portal describes a PreForm API served by PreForm on the host at localhost:44388. That host-side port is not a printer port. Formlabs Web API/Dashboard is a distinct internet-connected/cloud route.
- Anycubic's M7 Max product page labels LAN file transfer “Scheduled”; it cannot be reported as currently verified LAN functionality from that source. Its M7 Pro manual confirms Wi-Fi and the official connection guide requires app/account binding for the described app workflow, but neither establishes a public local protocol.
- Any value marked `unverified` above could not be supported from the cited/checked official material on the access date. The fleet's model list and launch comments are not evidence for technical specifications or connectivity.

## Driver coverage

- **Moonraker / Klipper (7125):** OpenFarm has a Moonraker driver, but no evidence reviewed links any of these resin appliances to Moonraker. No resin model is covered on that basis.
- **Bambu MQTT / FTPS:** OpenFarm has Bambu support, but none of the resin models is a Bambu model; no resin coverage.
- **Creality:** the prototype has Creality support for its documented FDM family. HALOT resin protocol compatibility was not established; no resin coverage.
- **Anycubic/KobraLink / SDCP:** the prototype's Anycubic path is Kobra/FDM-specific. It does not establish support for Photon resin printers; no resin coverage.
- **Elegoo, Phrozen, Formlabs:** no corresponding resin driver or verified LAN protocol found in OpenFarm's Connector/catalog/docs snapshot. Formlabs' Local API is a documented integration family, not an existing OpenFarm printer driver.
