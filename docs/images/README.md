# Capturas da interface

As imagens deste diretório são capturas reais do Open3DFarmManager em 5 de novembro de 2026, no commit `c6f1d6fc2342289793ee122f86f0136bfd4f16c2`.

| Arquivo           | Rota      | Viewport   |
| ----------------- | --------- | ---------- |
| `app-home.png`    | `/`       | 1280 × 540 |
| `app-login.png`   | `/entrar` | 720 × 650  |
| `app-pairing.png` | `/parear` | 720 × 800  |

O app rodou com `bun run --cwd apps/farm dev --port 3187`, em loopback, com a configuração padrão e sem sessão autenticada. A captura usou uma aba privada do navegador integrado ao T3 Code. Nenhum formulário foi enviado, nenhuma impressora foi conectada e nenhuma resposta de API ou elemento visual foi substituído. As imagens não comprovam autenticação, pareamento ou integração com hardware.

Para atualizar, execute o app localmente, abra as mesmas rotas sem credenciais ou dados pessoais, ajuste os viewports e salve os PNGs sem edição visual. Confira o conteúdo de cada imagem antes de substituir os arquivos e registre aqui o commit capturado. O indicador de foco na página inicial faz parte da interface real.
